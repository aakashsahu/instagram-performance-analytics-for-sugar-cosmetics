# Sugar Cosmetics - Instagram Analytics (Streamlit)

    pip install -r requirements.txt
    streamlit run app.py

Files: app.py (dashboard), analytics.py (metrics helpers), sugar_cosmetics_instagram_clean.csv (50,000 posts rebuilt from the source PDF), requirements.txt.
Tabs: KPI Overview, Posting Trend, Top Posts, Post Types & Campaigns, Day of Week, Engagement Funnel, Hashtags, Audience & Growth, Strategy & Insights, Data.
Sidebar filters: date range, post type, campaign, engagement source, audience emotion, hashtag.
Engagement rate = (likes + comments + shares + saves) / reach.
